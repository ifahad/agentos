The chain

It's the architecture.

Every request takes the same six stages in the same order. Most clear all of them. The ones that don't stop at the stage that stopped them, and every stage after it stays dark — because the request never reached it.

The platform

Four planes. One guarantee.

The gateway is the only component that ever holds a provider credential. Everything else borrows access from it, on a key you can revoke.

01

Governed model access

Virtual keys with their own org, budget and rate limit. Budget holds are reserved before the upstream call, so concurrent requests can't overspend a cap.

OpenAI-compatible402 on exhaustion
02

Deep agents, durable

LangGraph ReAct or deepagents, with Postgres checkpointing. Threads resume. Skills are baked into the image and never fetched at runtime.

HITL approvalssha256 provenance
03

Legacy systems as tools

SQL, REST, SSH, SOAP and a browser — each fronted by a connector that enforces its own safety constraint, not the model's good intentions.

read-only SQLcommand allowlist
04

Code that can't phone home

Generated Python runs in a Rust sandbox: cleared environment, rlimits, process-group kill, read-only rootfs — on a network with no route out.

no egresscaps dropped
05

Eval-gated self-improvement

The runtime proposes a better system prompt. It ships only when the evals pass and a human approves it. Nothing activates itself.

baseline vs candidate
06

Autonomy you can halt

Operators pursue standing objectives on an interval, a cron or a webhook — bounded by cycle caps, audited on the runtime's key, and off by default.

Multiverse

Many models. One verdict.
Honest dissent.

One objective fans out to model-bound members in parallel. A judge synthesises a single answer and an explicit dissent report — disagreement is recorded, not averaged away.

Quickstart

Stand it up in one command.

Compose brings up the gateway, the runtime, the sandbox, two connectors, Postgres and the console. Point it at local Ollama and the whole thing runs at $0, with no third-party call.

bash
# clone, configure, and bring the stack up
git clone <your-remote> agentos && cd agentos
cp deploy/.env.example deploy/.env
make up                    # gateway · runtime · sandbox · connectors · console
make smoke                 # end-to-end: an agent answers from the legacy DB

✓ console  http://localhost:3000
✓ gateway  http://localhost:8080/healthz
✓ runtime  http://localhost:8000/healthz
