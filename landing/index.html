Why AgentOS

Governance isn't a setting. It's the architecture.

The runtime holds no provider credentials. Every model call is issued through the gateway on a virtual key, so it is impossible for an agent — or an autonomous loop — to route around the budgets, limits, and audit that make it accountable.

Attributable01

Every action has a name

Virtual keys, orgs, and users mean each request is traced to who made it and what it cost — never an anonymous provider call.

Bounded02

Nothing runs unbounded

Atomic budget reservation stops a fan-out from overrunning; cycle caps and a kill switch bound every autonomous run.

Safe by default03

Read freely, propose writes

An unattended agent reads on its own but turns every write into a human-approved proposal — fail-closed, so an unknown tool is a write.

Multiverse council

Many models. One verdict. Honest dissent.

Route one objective to a council of model-bound agents, each on a different frontier model. A judge synthesizes their answers into a single verdict — and reports where they disagreed, instead of averaging it away.

  • / Call the whole council behind one OpenAI-compatible model name.
  • / Quorum and failure isolation — one bad vendor never denies the verdict.
  • / Two independent guards stop the council calling itself.

Operators

Governed autonomy — on a schedule, or a webhook.

Standing objectives the runtime pursues on its own: fire on an interval, a cron schedule, or an inbound webhook. Every run is governed, bounded by a cycle cap, and a write pauses for a human. The scheduler is opt-in and off by default.

  • / interval · cron · webhook triggers toward stored objectives.
  • / A run that needs approval is recorded, never auto-resumed.
  • / In-repo, checksummed skills the agent pulls on demand — never a registry.

Sovereign by design

Your agents. Your keys. Your infrastructure.

✳ Zero external services

The whole platform runs on your own hardware — gateway, runtime, sandbox, database. No third party sees your prompts or usage.

✳ Runs air-gapped

Local models mean a full five-model council answers at $0 with no internet at all. Bring frontier keys when you want them.

✳ Credentials never leave

Provider keys live in the gateway behind a pluggable secrets backend — env, encrypted file, or Vault — and the runtime never holds one.
